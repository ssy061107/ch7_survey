# 📊 생성형 AI 활용 인식 설문 데이터 분석 앱

본 프로젝트는 부산대학교 인문사회계열 1학년 학생들을 대상으로 한 **'생성형 AI 활용 인식'** 설문조사 데이터를 정제하고 시각화하기 위해 제작된 Streamlit 멀티페이지 애플리케이션입니다.

## 📁 디렉토리 구조

```text
📦 project_folder
 ┣ 📜 Home.py                # 앱의 메인 화면 (실행 파일)
 ┣ 📜 requirements.txt       # 필요한 파이썬 패키지 목록
 ┣ 📜 README.md              # 프로젝트 설명서
 ┗ 📂 pages
   ┣ 📜 1_데이터_정제.py       # 원본 CSV 데이터 업로드 및 정제 (결측치, 이상치, 중복 처리)
   ┗ 📜 2_그래프_분석.py       # 정제된 데이터 기반의 시각화 및 분석 대시보드
```

## 🛠️ 주요 기능

1. **데이터 정제 (`1_데이터_정제.py`)**
   - 구글 설문지 결과 파일(CSV) 업로드 기능
   - 이상치(AI 사용 시간) 허용 범위 설정 및 필터링
   - 결측치 처리 (그대로 두기 / 행 삭제)
   - 역문항 점수 자동 재계산 및 불필요한 중복 응답 제거
   - 정제 과정 기록 및 완료된 데이터 CSV 다운로드 지원

2. **그래프 분석 (`2_그래프_분석.py`)**
   - 유효 응답, 평균 사용 시간, AI 윤리의식 평균 등 요약 지표 제공
   - 정제 전/후 단과대학별 응답자 수 비교 차트
   - 응답자 구성, 문항별 평균, 집단(학년/단과대) 비교 통계 제공
   - AI 사용 시간과 AI 윤리의식 점수 간의 관계를 보여주는 산점도 제공

## 🚀 설치 및 실행 방법

1. **파이썬 환경 설정 및 패키지 설치**
   터미널(또는 명령 프롬프트)을 열고 프로젝트 폴더로 이동한 후 아래 명령어를 입력하여 필요한 패키지를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```

2. **애플리케이션 실행**
   패키지 설치가 완료되면 아래 명령어를 입력하여 Streamlit 앱을 실행합니다.
   ```bash
   streamlit run Home.py
   ```
   명령어를 실행하면 웹 브라우저가 자동으로 열리며 애플리케이션을 사용할 수 있습니다.
